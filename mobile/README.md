# Kalchat – coque Android (Capacitor)

L'appli ouvre https://kalchat.onrender.com dans une WebView : toute mise à jour du site
est visible tout de suite, sans refaire d'APK. L'APK n'est à refaire que pour changer
l'icône, le nom ou les autorisations.

Fabriquer l'APK : GitHub > onglet Actions > "Build APK Android" > Run workflow,
puis télécharger l'artefact "Kalchat-APK" en bas de la page du run.
